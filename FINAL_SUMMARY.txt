QUICK START
═══════════════════════════════════════════════════════════════════════════

1. Install Dependencies:
   npm install (in root)
   cd mobile && npm install --legacy-peer-deps

2. Start Development Server:
   cd mobile
   npm start
   (Press 'a' for Android or 'i' for iOS)

3. Test Wallet Connection:
   • Open app in emulator
   • Connect with Phantom/Backpack/Seeker
   • Verify wallet displays correctly

4. Explore Features:
   • Map: Check 4 quest locations
   • Staking: Verify APY calculation
   • PvP: Test arena interface
